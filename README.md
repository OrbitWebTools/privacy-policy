# Privacy Policy

Public Privacy Policy page for the WhatsApp automation service.

## GitHub Pages
1. Upload `index.html` to the repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

Your page will be available at:
`https://YOUR-USERNAME.github.io/privacy-policy/`

Before publishing, replace the business/service name and contact email in `index.html`.
